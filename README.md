# ⚾ ランダムフォレスト経験者のための LightGBM ＆ プロ野球ベストナイン予測モデル完全解説

プロ野球データFreak（2015〜2026年）および NPB公式ベストナイン得票結果を用いた、**LightGBM によるベストナイン予測モデル**の解説Webサイト＆分析リポジトリです。

## 🌐 公開Webサイト（GitHub Pages）

👉 **[https://achi07-ai.github.io/npb-bestnine-prediction/](https://achi07-ai.github.io/npb-bestnine-prediction/)**

### Webサイトの主な収録コンテンツ（全6タブ）
1. **🌲 RF vs LightGBM 徹底比較**: ランダムフォレスト（並列・多数決）と LightGBM（直列・残差学習）の違いと、投手 `max_depth=2`・野手 `max_depth=3` が最適である理由
2. **🧹 データ収集＆前処理**: プロ野球データFreak の複数テーブル・日別スタメン・NPB公式得票データの結合と表記ゆれ名寄せパイプライン（統合CSVダウンロード機能付き）
3. **⚙️ 特徴量エンジニアリング**: なぜ生の打率や本塁打数だけではベストナインを当てられないのか？相対Zスコア・当落線マージンの作り方
4. **🎯 特徴量からどう予想するか**: `pos_margin_cutoff_pos_weighted_RC`（重み付きRCの当落線差）の具体的な計算例と、決定木をたどって予測確率を出すインタラクティブ・シミュレーター
5. **🔍 2024・2025 誤予測の原因分析**: テスト期間（2024〜2025年）の全38枠中、外れた7枠すべてのデータ・記者投票心理の徹底解剖
6. **🏆 精度検証＆2026年ベストナイン予想**: 11年分の交差検証結果と、2026年シーズンのベストナイン予測結果

## 📂 主なファイル構成
- `index.html` / `web/index.html`: インタラクティブ解説Webサイト本体（統合CSVのワンクリックダウンロード機能内蔵）
- `web/master_hitters_2015_2026.csv`: 打者統合マスターCSV（2015〜2026年・4,140行×86列）
- `web/master_pitchers_2015_2026.csv`: 投手統合マスターCSV（2015〜2026年・4,158行×54列）
- `web/master_all_players_unified_2015_2026.csv`: 打者＋投手 完全統合マスターCSV（8,298行×125列）
- `fetch_data.py`: データ収集スクリプト
- `train_models.py`: 特徴量生成・LightGBM学習・評価スクリプト
- `analyze_errors.py`: 2024〜2025年の誤予測7件の詳細分析スクリプト
